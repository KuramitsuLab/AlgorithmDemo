テープ・ヘッド・レジスタだけで、足し算から階乗まで計算できる — 命令を1つずつ動かして確かめよう

① テープとヘッド（セルをダブルクリックで値を直接編集）

▲
M[0]

セルの下の数字はベースポインタ bp からの相対番号 M[n]。CALL するとヘッド位置が新しい M[0] になり、RET で元に戻る（関数ごとの作業領域）。値が書かれたセルは緑で表示。

命令一覧

命令動作
SET nレジスタに n を入れる
LEFT / RIGHTヘッドを1マス左／右へ
MOVE [n]ヘッドを M[n] へ移動。n を省略するとレジスタの値の位置へ
READ / WRITEヘッドのセル → レジスタ ／ レジスタ → ヘッドのセル
INC [n] / DEC [n] / NEGレジスタを +n／−n（既定 1）／符号反転
JUMP ラベル無条件ジャンプ（行番号も可）
IFZERO / IFNEG ラベルレジスタが 0／負なら、そのラベルへジャンプ
CALL ラベル / RETサブルーチン呼び出し（ヘッド位置が新しい M[0]）／呼び出し元へ復帰。CALL なしの RET はプログラム終了

足し算は「INC を B 回くり返す」、掛け算は「足し算を B 回くり返す」…と、ごく小さな命令の組み合わせから複雑な計算が作れる。1 回の実行は最大 20000 ステップまで。
