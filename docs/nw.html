🧮 何をしている？

出力 = σ( W₂ · f(W₁·x + b₁) + b₂ )

入力 x（点の座標）を、重み W とバイアス b で変換して 0〜1 の確率にする。 誤差を 逆伝播 して各重みを少しずつ直す（＝勾配降下）。これを繰り返すのが「学習」。

⚙️ 最適化手法

SGD：勾配の向きに素直に一歩ずつ（遅い）。
モメンタム：慣性で加速し、谷で振動しにくい（速い）。
Adam：重みごとに歩幅を自動調整（速く安定。ηは自動で小さめに）。
同じ設定で切り替えて「損失の推移」で収束の速さを見比べよう。
