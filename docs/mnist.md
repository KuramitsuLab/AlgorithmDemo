# 手書き数字を「教師あり学習」で覚える — `docs/mnist.html`

たった **40 枚** の数字画像と「正解」を見せるだけで、小さなニューラルネットは手書き数字を読めるようになるのか？
本物の MNIST（28×28）を思いきり小さくした **ミニ版** で、**教師あり学習の一部始終**をブラウザ上で眺める教材です。

---

## 1. 教師あり学習とは

「問題（画像）」と「答え（正解ラベル）」を **セット** で大量に見せ、答えを当てられるように直していく学習方法です。
この組を **教師データ** と呼びます。

```
画像（問題）   →  ネット  →  「3 かな？」（予測）
正解 = 7                      ↑ ずれている → 誤差を測って、重みを直す
```

画面の「📘 教師データ」の欄が、まさにこの組です。

- 上段：学習に使う画像
- 中段：**正解 7**（人間が与えた答え＝教師）
- 下段：**答 3 ×**（いまのネットの予測と、○／×）

最初は 10 枚中ほぼ全部が赤（×）。学習が進むと枠が緑（○）に変わっていきます。
**「教師の答えに近づくように、ネットが書き換わっていく」** のが教師あり学習です。

> 教師データは多いと画面に収まらないので、**クラスを均等に回して最大 20 件に間引いて**表示しています（学習そのものは全件を使います）。

---

## 2. 使い方

```bash
open docs/mnist.html
```

1. 上の **▶ 学習** を押すと、エポック（全データを 1 周する単位）が進みます。
2. 教師データの枠が赤→緑に変わり、右上のグラフで損失が下がり正解率が上がります。
3. **太枠**が 1 件ずつ巡回し、下の説明文が「この画像は『0』と教えられた。ネットは 100% 予測 → 誤差を逆伝播して重みを更新」と、その 1 件の様子を説明します。
4. 左上の **手書きパッド** に自分で数字を描くと、その時点のネットの認識が右の棒グラフ（各数字らしさ＝確率）に出ます。

操作は `⏮ ◀ ▶ ⏭` とシークバーで、**戻る・進む・好きな時点へジャンプ**も自由です（学習の全過程を先に記録してあります）。
キーボードは `←` `→` で 1 ステップ、`Space` で学習の開始／停止、`R` で初期値を変えて再学習。

| つまみ | 既定値 | 意味 |
|---|---|---|
| 使う数字 | 0〜9（10 クラス） | 分類する数字の種類。2 → 5 → 10 で難しくなる |
| 解像度 | 10×10 | 画像をこの大きさに縮小して入力する |
| 学習データ | **40 件** | 教師データの総数（10 クラスなら 1 数字 4 枚） |
| 隠れ層 | **32 個** | 隠れ層のユニット数。「なし」だとテンプレート学習 |
| 学習率 η | 0.50 | 1 回の更新で重みをどれだけ動かすか |
| エポック数 | 300 | 学習を何周するか |

## 3. ネットの中身

入力 **10×10 = 100 ピクセル** → 隠れ層 **32 ユニット（ReLU）** → 出力 **10 クラス（softmax）**。
パラメータ（重みとバイアス）は合計 **3562 個** です。

```
100 ピクセル ──W1──▶ 32 ユニット ──W2──▶ 10 個の「らしさ」──softmax──▶ 確率
```

### 順伝播
各ユニットは「入力 × 重み」を足し合わせ、ReLU（負は 0）を通します。
最後に **softmax** で 10 個のスコアを「合計 100% の確率」に直します。

### 誤差（損失）
正解クラスに付けた確率を `p` として、**交差エントロピー** `−log p` を誤差にします。
正解に 100% 振れば 0、当てずっぽう（10 クラスで 10%）なら約 2.3。
学習開始時の損失がちょうど 2.3 前後なのは、この「当てずっぽう」の値です。

### 逆伝播と更新
softmax と交差エントロピーを組み合わせると、出力側の誤差は **「予測確率 − 正解（one-hot）」** という単純な形になります。
これを出力層から入力側へ順に伝え、各重みの勾配を求めて、勾配の逆向きに少しずつ動かします（勾配降下）。
この教材では **全データをまとめて 1 回更新（フルバッチ）＋モメンタム 0.9** です。

## 4. 「手書き風」データの作り方

本物の MNIST ファイルは使わず、**ブラウザの上でデータを自作**しています（外部ファイル不要）。

1. 数字のフォントを大きな canvas に描く
2. **回転（±約 9°）・移動・拡大縮小・ノイズ** をランダムに加えて「手書き風」にばらつかせる
3. 10×10 などに縮小して、濃さ 0〜1 のベクトルにする

乱数はシード固定なので、同じ設定なら毎回同じデータ・同じ学習になります。

> **少ないデータほど、変形は穏やかに。**
> 40 枚しかないのに回転・移動を大きくかけると、ネットは「いろんな形があること」を学びきれず、
> テスト正解率が 30〜40% に留まりました。変形を穏やかにすると約 **70%** まで上がります。
> データの質とばらつきの設計が、精度を左右することも体感できます。

## 5. 見どころ・実験

### ① 学習データは 100% 正解、でもテストは？
既定（40 件）では、**学習データの正解率はほぼ 100%** になりますが、**テスト正解率は約 70%** です。
ネットは見せられた 40 枚を覚えきっていても、**初めて見る字**には間違えることがある。
この差が **汎化**（未知のデータに通用する力）の問題です。差が大きいとき、画面には「⚠ 過学習ぎみ」と出ます。

### ② 件数を増やす（40 → 100 → 200）
教師データを増やすとテスト正解率が上がり、学習／テストの差が縮みます。
**「教師データは多いほどよい」** を数字で確かめられます。

### ③ クラス数を変える（2 → 5 → 10）
0 と 1 だけなら簡単に当たりますが、10 クラスでは似た字（3 と 8、1 と 7 など）の取り違えが出ます。
パッドに描いて、**間違えやすい数字を探して**みましょう。

### ④ 隠れ層を「なし」にする
隠れ層なしだと、重みの各行がそのまま **数字ごとのテンプレート画像** になります
（赤＝そこにインクがあれば加点、青＝減点）。
隠れ層 32 個にすると、数字そのものではなく **「線・丸・はらい」のような部品（特徴検出器）** が学ばれていきます。

### ⑤ 学習率を変える
大きすぎると損失が暴れ、小さすぎるとなかなか下がりません（`docs/grad.html` と同じ現象）。
