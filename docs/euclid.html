ユークリッドの互除法（引き算版）

A = B なら答え。A > B なら A ← A − B、A < B なら B ← B − A。引き続けると最大公約数が残る
0 / 0

アルゴリズム

while A != B:    if A > B:        A = A - B    else:        B = B - A答え = A   # = B
割り算（余り）を使わず、引き算だけで最大公約数が求まる。
