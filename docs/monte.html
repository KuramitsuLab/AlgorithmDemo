正方形に乱数で点を打つだけで円周率 π が求まる — 点の数 N を増やすと π̂ はどう近づく？

←→ 点を1個ずつ（Shift併用で10倍）／ Space 再生・停止 ／ R 乱数をふり直す。 シークバーは対数目盛（左端 N=0、右端 N=Nmax）。

① 正方形に点を打つ（赤＝円の内側 / 青＝外側）

x²+y² ≤ 1（内側） 外側

一辺1の正方形（面積1）に四分円（面積 π/4）。
点が内側に入る確率 ＝ π/4 なので、π ≈ 4 × (内側の数) ÷ N。

— N = 0 内側 = 0 誤差 = —

② N を増やすと π̂ はどう変わる？（横軸は対数）

この試行の π̂ 別の試行 真の π = 3.14159… ±2σ の目安（σ ≈ 1.64/√N）

③ 誤差 |π̂ − π| は N とどう減る？（両対数）

この試行の誤差 1/√N の線（傾き −½）

誤差はおおよそ 1/√N で減る。つまり精度を10倍にするには点を100倍打つ必要がある。 収束は遅いが、次元が増えても同じ速さで済むのがモンテカルロ法の強み。
