🧩 再帰の式

def hanoi(n, 出発, 到着, 経由):
    if n == 0: return
    hanoi(n-1, 出発, 経由, 到着)  # ①
    move(n, 出発 → 到着)         # ②
    hanoi(n-1, 経由, 到着, 出発)  # ③
n 枚＝(n−1 枚)×2 回＋1 回。T(n) = 2·T(n−1) + 1 より T(n) = 2ⁿ − 1。

📈 枚数と移動回数

n=64 なら 2⁶⁴−1 手。1秒1手でも約 5800 億年。
